Spring Auth + ElevenLabs Token

ElevenLabs 토큰 발급 구조

API key는 Spring orchestrator만 보관. Browser는 인증 cookie로 Spring에 token 요청. 발급받은 single-use token으로 ElevenLabs Realtime Scribe WebSocket 직접 연결.

1. Runtime Sequence

사용자 인증 → 권한 확인 → ElevenLabs single-use token 발급 → WebSocket 전사.

sequenceDiagram
    autonumber
    actor U as User
    participant B as Browser / LiveLectureRoom
    participant S as Spring Orchestrator
    participant DB as Postgres
    participant T as ElevenLabs Token API
    participant W as ElevenLabs Realtime WS

    U->>B: Click mic start
    B->>S: POST /api/scribe/token
Cookie: accessToken
    S->>S: JWT validate
@AuthenticationPrincipal
    S->>DB: Verify authenticated user
future: lecture auth check
    DB-->>S: auth ok
    S->>T: POST /v1/single-use-token/realtime_scribe
Header xi-api-key
    T-->>S: { token }
    S-->>B: 200 { token }
    B->>W: wss connect
model_id + token + language_code=ko
    loop while recording
        B->>W: PCM16 audio chunks
sample_rate=16000
        W-->>B: partial_transcript
        W-->>B: committed_transcript
    end
    U->>B: Stop mic
    B->>W: commit + close
